# Netflix Analytics Project
A collaborative Data Science mini project analyzing Netflix movies and TV shows using Python, data analysis, data visualization, Git, GitHub and Markdown.

## 1. Project Overview
Netflix provides a wide variety of movies and television shows across different genres, countries and release years.

This project explores the Netflix titles dataset to identify patterns and trends in the content available on the platform. The project also demonstrates collaborative work using Git and GitHub.

## 2. Project Objectives
The main objectives of this project are:
- To explore and understand the Netflix dataset.
- To compare the number of movies and TV shows.
- To analyze the distribution of titles across release years.
- To explore popular genres and content-producing countries.
- To examine content ratings and title durations.
- To present findings using suitable visualizations.
- To practice teamwork, version control and collaboration using Git and GitHub.

## 3. Dataset Description
[Dataset source](netflix_titles.csv)

[Cleaned dataset file](netflix_cleaned.csv)

The dataset contains 8,807 records and 14 columns related to Netflix movies and TV shows.

The columns are as follows:

- `show_id`: Unique identifier for each title.
- `type`: Indicates whether the title is a Movie or TV Show.
- `title`: Name of the movie or TV show.
- `director`: Director of the title.
- `cast`: Actors associated with the title.
- `country`: Country associated with the title.
- `date_added`: Date the title was added to Netflix.
- `release_year`: Year the title was released.
- `rating`: Content rating.
- `duration`: Duration of a movie or number of seasons of a TV show.
- `listed_in`: Genres or categories of the title.
- `description`: Brief description of the title.
- `duration_min`: Duration in minutes for applicable titles.
- `seasons`: Number of seasons for applicable TV shows.

## 5. Planned Analysis
The project will explore the following questions:
1. How many movies and TV shows are present in the dataset?
2. How has the number of titles changed across release years?
3. Which genres occur most frequently?
4. Which countries are associated with the most titles?
5. How are content ratings distributed?
6. What can we learn about movie durations and TV show seasons?

## 6. Team Contributions
Each member is responsible for a part of the project, such as documentation, data cleaning, exploratory data analysis, visualization or interpretation of results.
