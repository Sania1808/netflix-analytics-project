# Netflix Analytics Project

## Project Overview
This is a collaborative Data Science mini project focused on learning and demonstrating the use of Git, GitHub, and Markdown in a team environment. The project uses a Netflix dataset as a practical example to organize files, document work, track changes and collaborate with team members.

## Main Objectives
- Understand and practise Git commands for version control.
- Learn how to create repositories, branches, commits and pull requests using GitHub.
- Collaborate with team members through forks and pull requests.
- Use Markdown to create clear and structured project documentation.
- Maintain and organize project files using Git and GitHub.
- Understand how version control helps teams work together on a shared project.
- Use a Netflix dataset as the subject of the Data Science mini project.

## Tools and Technologies
- **Git** 
- **GitHub**
- **Markdown** 
- **Python:** Jupyter Notebook and Google colab
    - *Packages: Pandas, Matplotlib*
- **Netflix Dataset** 

## Dataset Description
> The dataset contains 8,807 records and 14 columns related to Netflix movies and TV shows.

The columns are as follows:

- `show_id`: Unique identifier for each title
- `type`: Indicates whether the title is a Movie or TV Show
- `title`: Name of the movie or TV show
- `director`: Director of the title
- `cast`: Actors associated with the title
- `country`: Country associated with the title
- `date_added`: Date the title was added to Netflix
- `release_year`: Year the title was released
- `rating`: Content rating
- `duration`: Duration of a movie or number of seasons of a TV show
- `listed_in`: Genres of the title
- `description`: Brief description of the title
- `duration_min`: Duration in minutes for applicable titles
- `seasons`: Number of seasons for applicable TV shows

## Expected Outcomes
The project aims to produce a clear understanding of the Netflix titles dataset, identify useful patterns through exploratory data analysis, create meaningful visualizations and demonstrate effective teamwork using Git and GitHub.
